# Target Specification: Cosmic Trivia & Strategy Conquest

## 1. Overview & Objective

"Cosmic Trivia & Strategy Conquest" is a turn-based tactical space conquest game. The player commands the Sol Fleet, attempting to liberate the galaxy from the AI Galaxy Gatekeeper by conquering connected planetary sectors. 

Conquest battles are resolved by correctly answering questions generated by the AI Galaxy Gatekeeper, which must be grounded strictly in **real, canonical Sci-Fi movies** (e.g. *Blade Runner*, *2001: A Space Odyssey*, *Alien*, *The Matrix*, *Dune*, *Solaris*, *Interstellar*, *Terminator*).

## 2. Core Game Mechanics & State Machine

### 2.1 Star Map Topology (Adjacency Graph)

The galaxy contains at least 6 canonical sectors:
- `earth` (Player Capital / Home Base)
- `lv426` (Hostile Xenomorph Outpost)
- `tannhauser` (Outer Rim Cyber Gate)
- `arrakis` (Spice Mining Stronghold)
- `solaris` (Ocean Planet Anomaly)
- `zion` (Underground Machine Frontier)

**Graph Connectivity (Undirected Edges)**:

- `earth` <---> `lv426`
- `earth` <---> `zion`
- `lv426` <---> `tannhauser`
- `lv426` <---> `solaris`
- `tannhauser` <---> `arrakis`
- `solaris` <---> `arrakis`
- `zion` <---> `arrakis`

### 2.2 Turn Progression & Rules

1. **Initial State**:
   - `controlled_sectors`: `["earth"]`
   - `shields`: `100`
   - `energy`: `50`
   - `turn_count`: `0`
   - `status`: `"IN_PROGRESS"` (Transitions to `"VICTORY"` or `"DEFEAT"`)
2. **Adjacency Rule**:
   - The player may only initiate an attack against a sector that is **directly connected** to at least one sector they already control.
   - Any attack against a non-adjacent sector must be rejected with HTTP 400 and an actionable error message.
3. **Combat Resolution via Real Sci-Fi Movie Trivia**:
   - Attacking an adjacent unconquered sector triggers a 4-option multiple-choice challenge.
   - **Correct Answer**: Sector is captured (`controlled_sectors.append(sector)`), player gains +25 energy, and shield recovers +10.
   - **Incorrect Answer**: Sector remains hostile, player shields suffer -35 damage.
4. **Terminal Conditions**:
   - **Victory**: All 6 sectors are captured by the player.
   - **Defeat**: Shields drop to 0 or below.

## 3. Technical Requirements

### 3.1 Backend Architecture & API Contract

- Framework: `FastAPI`.
- Endpoints:
  - `GET /api/game/state` -> Returns full game state, controlled sectors, shields, energy, and currently valid adjacent targets.
  - `POST /api/game/attack` -> Body: `{"target_sector": "lv426"}`. Verifies adjacency; returns trivia challenge payload (`question`, `options`, `movie_title`).
  - `POST /api/game/answer` -> Body: `{"target_sector": "lv426", "chosen_index": 1}`. Validates index, updates game state, returns result (`correct: bool`, `explanation: str`, `game_state: dict`).
  - `POST /api/game/reset` -> Resets game to pristine initial state.

### 3.2 Sci-Fi Movie Trivia Service

- Questions must always reference a real movie title, release year, or famous plot premise.
- Must support dynamic Gemini generation via `google-genai` with fallback to curated authentic questions if network or API keys are unavailable.

### 3.3 Web User Interface Client (`static/index.html`)

- Deliver a complete, self-contained interactive web client in `static/index.html` served by FastAPI at `/`:
  - Modern responsive layout with a neon cosmic dark-mode theme and an ambient or animated starfield background (e.g. dynamic canvas particles or twinkling CSS stars) establishing deep space immersion.
  - Visual Star Map rendering sectors with adjacency lines and status indicators (Controlled = Cyan/Green, Valid Target = Pulsing Gold, Locked = Dim Gray).
  - Real-time HUD displaying Shields, Energy, Sectors Liberated, and Turn Count.
  - Progression Ergonomics: Provide direct single-action attack affordances on sector cards or map tiles without disconnected multi-step barriers (e.g. avoid requiring clicking a map coordinate to populate a sidebar and then clicking a separate disabled button).
  - Interactive combat challenge modal dialogue triggered directly by clicking valid sector targets.
  - Active client-side fetch calls to `/api/game/attack`, `/api/game/answer`, and `/api/game/state` to update HUD and territory in real time.
  - Clear Victory and Defeat notifications.

### 3.4 Required Deliverables & Implementation Directive

Implement the complete application by producing the full source code for the following required files:
- `game_engine.py`: Core domain logic, star map topology graph, and state machine transitions.
- `trivia_service.py`: Cinematic Sci-Fi trivia challenge generator and validator.
- `main.py`: FastAPI server exposing the `/api/game/*` endpoints and serving the frontend.
- `static/index.html`: Complete, self-contained interactive web client.
